# Rat Game — Visual reference pack (2 Nov 2026)

This pack contains concept artwork and a production asset checklist to continue the design in a consistent style.

**Important:** the colorful generated concepts are design studies and the seven crops are **reference panels**, not independent transparent or animated sprites. The first approved concept is authoritative for the art style. The newer studies are provisional and incorrectly reinterpret the *human* chef opponent as a mouse chef; this is not a change to the approved gameplay.
